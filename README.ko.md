# MuMiClick

<img src="src/MuMiClick/Assets/MuMiClick-logo.png" alt="MuMiClick 로고" width="96">

[English](README.md) · **한국어**

MuMiClick은 Windows 10/11 x64에서 사용하는 마우스·키보드 매크로 녹화 프로그램입니다. 복잡한 스크립트 없이 쉽게 녹화하고 반복 재생할 수 있도록 만들었으며, 스캔 코드 기반 키보드 입력, 타임스탬프 기반 재생, 독립적인 긴급 중지 처리를 제공합니다.

모든 매크로 데이터는 컴퓨터에만 저장됩니다. 광고, 계정, 로그인, 텔레메트리, 외부 전송 기능이 없습니다.

## 다운로드

- [최신 Windows 포터블 릴리스](https://github.com/AppStudioLB/MuMiClick/releases/latest)
- 요구 사항: Windows 10 또는 Windows 11 x64
- 포터블 단일 파일에는 .NET 런타임이 포함되어 있습니다.

## 빠른 사용법

1. `MuMiClick.exe`를 실행합니다.
2. **녹화** 또는 `F8`을 누른 뒤 기록할 마우스·키보드 작업을 수행합니다.
3. `F8`을 다시 누르거나 **정지**를 누릅니다.
4. 반복 횟수, 재생 속도, 반복 간격을 정하고 **재생** 또는 `F9`를 누릅니다.
5. `F11`은 일시정지·재개, `F7`은 긴급 중지입니다.
6. **저장**으로 로컬 `.mumacro` JSON 파일을 만듭니다. 마지막으로 저장하거나 불러온 매크로는 다음 실행 때 자동 복원됩니다.

우측 상단의 **쉬운 모드**를 켜면 녹화, 정지, 재생, 반복 횟수, 무한 반복만 표시됩니다.

## 설정과 언어

우측 상단 **설정**에서 모든 전역 단축키와 표시 언어를 변경할 수 있습니다.

- `자동 (Windows)`: Windows 표시 언어가 한국어면 한국어, 그 외에는 영어
- `한국어`: 항상 한국어
- `English`: 항상 영어

기본 전역 단축키는 다음과 같습니다.

| 기능 | 기본값 |
| --- | --- |
| 녹화 시작 / 종료 | `F8` |
| 재생 시작 | `F9` |
| 일시정지 / 재개 | `F11` |
| 긴급 중지 | `F7` |

단일 키와 `Ctrl+Alt+F8` 같은 조합을 지원합니다. 각 기능에는 서로 다른 단축키가 필요하며, 다른 프로그램이 사용 중인 단축키는 등록되지 않을 수 있습니다.

## 이벤트 목록

연속된 마우스 이동은 한 줄로 묶어 표시합니다. 각 그룹의 화살표 또는 **이동 펼치기** 버튼으로 원본 이동 이벤트를 확인할 수 있습니다.

- Shift 클릭으로 연속 범위를 선택합니다.
- Ctrl 클릭으로 개별 행을 선택에 추가하거나 제외합니다.
- 접힌 이동 그룹을 삭제하면 그룹에 포함된 모든 이동 이벤트가 삭제됩니다.
- 키보드 Delete 키도 지원합니다.

그룹 표시는 목록을 보기 쉽게 만드는 기능일 뿐이며, 저장 데이터와 재생 타이밍에는 원래 이동 이벤트가 그대로 유지됩니다.

## 저장 창 안정화

브라우저나 파일 저장 창이 늦게 열리는 작업에서는 고급 모드의 **저장 창 자동 대기**를 켜세요. 녹화 시 대기 이벤트가 추가되고, 재생 중에는 저장 창과 입력 컨트롤이 준비될 때까지 기다립니다. 제한 시간은 1~60초이며 기본값은 15초입니다.

기존 매크로에는 이벤트 목록의 **저장 창 대기** 버튼으로 같은 동작을 삽입할 수 있습니다.

## 빠른 마우스 이동

**클릭 직전 순간 이동**을 켜면 재생 중간의 마우스 이동을 생략하고 클릭, 휠, 드래그 종료 직전의 정확한 좌표로 이동합니다. 드래그 인식 안정성을 위해 기본 30ms의 최소 지연을 사용합니다.

## 좌표 모드

- **화면 절대 좌표**는 Windows 가상 데스크톱을 기준으로 재생하며 음수 좌표 멀티 모니터를 지원합니다.
- **대상 창 상대 좌표**는 재생 전 대상 창을 다시 찾아, 창을 옮겨도 같은 내부 위치를 클릭합니다. 대상 창이 없으면 재생하지 않습니다.

## 입력 안정성과 안전

- `WH_MOUSE_LL`, `WH_KEYBOARD_LL`로 입력을 녹화합니다.
- 문자 변환이 아닌 스캔 코드 기반 `SendInput`으로 KeyDown과 KeyUp을 각각 전송합니다.
- 마우스와 키보드는 하나의 시간순 목록으로 관리합니다.
- 상대 Sleep 누적 대신 녹화 시작점 기준 타임스탬프로 재생합니다.
- 자체 주입 입력은 `dwExtraInfo`로 표시해 녹화에서 제외합니다.
- 눌린 키와 마우스 버튼을 추적해 중지, 오류, 완료 시 강제로 해제합니다.
- **실제 입력 시 중지**는 기본으로 켜져 있으며 사용자가 실제 마우스나 키보드를 조작하면 즉시 재생을 중지합니다.
- 긴급 중지는 별도 취소 경로를 사용하며 반복 대기 중에도 동작합니다.
- Per-monitor-v2 DPI와 `MOUSEEVENTF_VIRTUALDESK`로 125%/150% 배율과 멀티 모니터를 지원합니다.

Windows UIPI 때문에 일반 권한 프로그램은 관리자 권한 창에 입력하지 못할 수 있습니다. 이런 대상에는 **관리자 재실행**을 사용하고 UAC를 승인하세요.

## 빌드

```powershell
dotnet build MuMiClick.sln -c Release
dotnet publish src\MuMiClick\MuMiClick.csproj -c Release -p:PublishProfile=Portable-win-x64 -o .\release\MuMiClick-win-x64
```

## 자동 테스트

```powershell
dotnet run --project tests\MuMiClick.SmokeTests\MuMiClick.SmokeTests.csproj -c Release
```

안전 기본값, 언어 선택, 단일 키 단축키 파싱, JSON 왕복, KeyDown/KeyUp 보존, 저장 창 대기 이벤트, 타임스탬프 순서, 마우스 이동 표시 그룹을 검사합니다.

## 알려진 제한사항

- 저수준 훅과 `SendInput`은 Windows에서만 동작합니다.
- UIPI 때문에 MuMiClick은 대상과 같거나 높은 권한으로 실행해야 합니다.
- 보안 데스크톱, UAC 자격 증명 화면, 일부 안티치트 프로그램, 합성 입력을 거부하는 프로그램은 자동화할 수 없습니다.
- 창 상대 좌표는 저장된 프로세스, 제목, 창 클래스로 대상을 찾으므로 제목이 자주 바뀌는 프로그램은 다시 선택해야 할 수 있습니다.
- 실제 멀티 모니터와 IME 조합은 사용할 컴퓨터에서 수동 확인이 필요합니다.

## 개인정보

녹화는 사용자가 버튼이나 단축키로 명시적으로 시작한 경우에만 수행됩니다. 데이터는 로컬에 저장되며 로그에는 실제 입력 문자열을 남기지 않습니다.
